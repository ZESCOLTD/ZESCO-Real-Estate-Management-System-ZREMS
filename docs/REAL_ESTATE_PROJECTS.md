# Real Estate Projects

The proposal form saves a draft to one `real_estate_projects` record and generates a `REP-YYYY-NNN` reference. Proposal responses are stored in `proposal_data` on that record.

The dashboard, register, proposals, approvals and reports pages use this project record. Approval actions, document uploads and the remaining assessment forms are not yet connected.

Saving the proposal form keeps the project in draft; it does not submit the project for approval.
